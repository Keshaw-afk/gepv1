To generalize this:
We provide object building blocks
Teacher uses these building blocks to draw a graph (say)
We provide interaction api to interact with the graph nodes, color(i, red)=> color the node i with red color. join(i, j) => join the node i, j

The teacher uses this interaction api to write ANY algorithm (DFS, BFS, Diameter of graph)

And it draws it.

    print/process start_vertex

        if neighbor is not visited:
            DFS(graph, neighbor)
